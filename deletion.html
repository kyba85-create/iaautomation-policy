Удаление данных IAautomation

Инструкция для текущего тестового этапа. Редакция от 13 октября 2026 года.

По вопросам данных приложения обращайтесь к администратору Tykshaev Ivan Alexandrovich по адресу trkatast@gmail.com.

  1. Напишите письмо с темой «Удаление данных IAautomation».
  2. Укажите имя вашего Instagram-аккаунта и примерную дату взаимодействия с приложением. Не присылайте пароль, токены, паспорт, фото или видео ребёнка.
  3. При необходимости администратор попросит подтвердить владение аккаунтом. Это можно сделать сообщением из соответствующего профиля; пароль передавать не требуется.
  4. Администратор проверит наличие технических записей, которые можно связать с вашим обращением, вручную обработает запрос и сообщит результат по электронной почте. Если данных недостаточно для установления связи с техническими записями, он сообщит об этом и уточнит необходимые сведения.

Автоматическая процедура поиска по имени профиля и удаления данных сейчас не реализована. Приложение не сохраняет полную переписку, фото и видео в своей базе. Удаление технических записей IAautomation не удаляет сообщения из Instagram. Для удаления сведений, хранящихся самой платформой, используйте настройки и средства Instagram.
